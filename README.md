# EW Market Intelligence

A static TradingView-based analysis workspace for EURUSD, GBPUSD and XAUUSD.

## Deploy with GitHub Pages
1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.
4. Wait for the Pages deployment to finish. The site URL should be:
   https://emawright.github.io/ew-market-intelligence/

## Included
- Embedded TradingView charts with W1, D1, H4, H1, M15 and M5 views.
- Local trade journal with manually recorded outcomes and R multiple.
- Supply/demand register.
- Manual multi-timeframe analysis notes.
- Daily/weekly review checklist.
- Editable TradingView symbol mappings.

## Limitations
This is a static client-side site. It does not access TradingView candle data, calculate automated BOS/CHOCH, issue live market signals, run scheduled reports, connect to MT5/Deriv, sync browser storage across devices, or execute trades. Journal and settings data remain in the current browser. Verify chart feed and quotes against your broker before acting.
